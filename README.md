# 孤舟码字 GuZhouWriter

> 面向网络小说 / 长文本创作者的本地优先写作工具。  
> 当前版本：**V2.2.5**

## 产品定位

孤舟码字围绕长篇创作中的章节管理、设定整理、防丢稿、朗读校稿与跨设备继续写作等场景持续迭代。

产品采用 **本地优先 + 手动章节级云同步** 的设计：即使不配置云端，也可以完整使用本地写作能力；需要跨设备时，再由用户主动选择章节上传或更新。

## 核心功能

- 书籍 / 卷 / 章节结构化管理
- 人物设定、世界观、事件卡
- 自动保存、历史版本、撤销 / 重做
- 搜索 / 替换、中文字数统计
- TTS 正文朗读，支持在线自然语音与本地中文语音备用
- Supabase 邮箱登录与云端书架
- 当前章节手动上传、单章节更新到本机
- 本地优先，离线仍可继续写作

## 产品设计思路

孤舟码字不是单纯增加功能，而是围绕长期创作流程逐步解决问题：

```text
基础写作
   ↓
长篇内容组织
   ↓
编辑效率与防丢稿
   ↓
桌面端长期使用体验
   ↓
TTS 听稿校稿
   ↓
跨设备继续创作
   ↓
章节级、安全可控的云同步
```

## 安全说明

请勿将以下信息提交到公开仓库：

- Supabase `service_role` / Secret Key
- 数据库密码
- 真实 Session / Token
- 私人小说正文或其他敏感数据

客户端配置只应使用 Supabase 可公开使用的 `Publishable Key`（旧项目可能显示为 `anon key`）。
